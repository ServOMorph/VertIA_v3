Bienvenue dans VertIA

1. Vérifiez vos moteurs ci-dessous. Le chat utilise Ollama ; image, musique et vidéo sont facultatifs.

2. Écrivez votre demande dans Discussion. Pour créer un fichier, relisez la carte proposée puis validez-la.

3. Retrouvez le résultat dans Fichiers. Mémoire affiche la tâche en cours ; les moteurs se relaient sur le GPU.

Comment démarrer le chat avec Ollama ?
  1. VertIA démarre automatiquement le service Ollama installé sur cet ordinateur, ou réutilise celui qui fonctionne déjà. Le badge en haut indique son état et les modèles chargés.
  2. Le modèle défini dans les réglages est préchargé au démarrage. Le badge indique l’attente du GPU, le chargement puis le nom du modèle chargé. Les modèles installés apparaissent automatiquement dans la liste.
  3. L’adresse habituelle est http://127.0.0.1:11434. Si vous changez cette adresse dans les réglages ci-dessous, enregistrez et redémarrez VertIA.
  4. Cliquez « Accéder à la discussion », puis « Nouvelle discussion », écrivez votre message et cliquez « Envoyer ». Si vous choisissez un autre modèle ou si le précédent a été déchargé, il sera chargé à la demande.

Si aucun modèle n’est installé, installez-en un dans Ollama avant de poursuivre. VertIA ne télécharge pas les modèles.

Chemins et modèle de chat

Indiquez les dossiers contenant les moteurs déjà installés. Ces réglages prennent effet après un arrêt puis un relancement de VertIA.

Le diagnostic ne lance aucun moteur et ne télécharge aucun modèle. Un moteur arrêté peut être correctement installé. La présence d’un fichier ne garantit pas une génération réussie.
